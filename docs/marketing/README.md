# Marketing files

## QR code for courts and the school

- `card-qr.png` (1200 x 1200) and `card-qr.svg` open `https://demariomontezpb.com/card`.
- That link lands on the homepage tagged as "QR card", so bookings from it say
  "Found you through: QR card" in DeMario's booking email (see `docs/ANALYTICS.md`).
- High error correction (level H), so it still scans when printed small or slightly
  covered. Checked by decoding the PNG on 2026-10-23.

DeMario can save the PNG to his phone's photos and show it to people at courts, with
nothing printed. A printed card needs his approval of the wording around the code;
the code itself never changes, even if the site's homepage does.
